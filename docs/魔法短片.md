# 魔法短片：点亮霍格沃茨（59 秒）

上一版运镜（3 分 55 秒，`docs/运镜.md`）太长、太平。这一版只有 59 秒，一条线索：一团魔法光从黑湖上亮起，
一路把沉睡的城堡点亮。没有人物，那团光就是"施法"本身。全片夜景。

代码在 `src/js/89-short.js`（镜头表和编排）和 `src/js/87-magic.js`（特效引擎），用运镜的播放器放，网址加 `?cut=magic`。

## 特效是怎么做的

- **火花**（`87-magic.js` 的 `Sparks`）：每颗火花是一个关于时间的公式：出生的地点、时刻和速度，在重力和空气阻力下飞、
  带一点飘动，所以任何一帧都能单独渲染。顶点着色器把它画成一道从"一个快门之前（或者它自己的拖尾长度之前）"到"现在"的光痕，
  运动模糊和长曝光的拖尾都是现成的；拖尾往后渐细。颜色是线性 HDR，靠管线里的泛光出光晕。种类：自由飞的、被吸向目标点的
  （开头聚拢的光点、片尾写字的火花，落定时闪一下）、悬在空中只在光团经过时才闪的灰尘
- **光团**（`ORB`）：屏幕空间画的核、光晕、星芒和横向镜头光（远了也保留几个像素），再加一盏跟着走的局部灯，照亮水面、崖壁、墙
- **施法的波前**（`00-core.js` 的 `SPELLU` / `cgSpell`）：一个从某点向外（或者沿某个方向）推进的波前。所有自发光材质
  （窗户、灯笼、蜡烛、火盆、壁炉、门洞的光）、光晕和局部灯光都乘上它：波前到达之前是暗的，经过时猛亮一下再落回正常亮度，
  每 3 米一格随机早一点晚一点；波前上还有一道金光刷过表面。默认半径无穷大，所以原来的页面和运镜都不受影响
- **光泡**（`SHELL_MAT`）：和波前同步长大的一个球面，只在边缘发光，带一点流动的纹理
- **天花板的云**（`62-interior.js` 的 `INTSKY.uClear`）：夜里以某个方向为中心、在某个角度以外盖一层厚云，边上一圈金色
- **烟花**（`fireShell`）：火箭带着火花尾巴升空，在爆点炸成星（牡丹带一个另一种颜色的花心、噼啪的每颗星最后再碎成白色的爆点、
  金柳是慢慢垂下的长尾），一闪，再加一盏按颜色闪一下、一两秒内熄灭的灯，照亮城堡和湖
- **写字**（`textPoints`）：在画布上写 "Hogwarts"（IM Fell English SC 字体），取字形里的点作为火花的目标
- **曝光**：大部分镜头按画面自动调色阶；"由暗到亮"的镜头（3、4、5）在 `lockAt` 指定的时刻测一次色阶，整个镜头锁住，
  灯亮起来才真的是变亮，而不是被自动曝光拉平


## 怎么出片

```
node tools/serve.mjs
node tools/film.mjs --spp 6 --w 1920 --h 1080 --out out/short/final --name hogwarts-magic --params cut=magic
```

调机位用 `node tools/probe.mjs 片段.js out/probe/x 960x540 cut=magic`，
片段里 `tourStill('hall', 3.0, 4)` 出指定镜头指定时刻的一帧。
