# 运镜：开学之夜到第二天清晨

按原著第一部第六、七章新生入学的顺序走：火车到站 → 跟着海格的灯笼下到湖边 → 四人一条船过黑湖 → 上岸、爬石阶到城堡大门 →
门厅（看一眼大理石楼梯）→ 大礼堂的分院和开学晚宴 → 晚宴之后由级长带着上大楼梯回宿舍。夜在楼梯井顶上结束，
第二天早上把整个城堡和场地飞一遍，最后停在湖上看城堡的全景。

原著和电影不一样的地方取电影的地理：新生在船屋上岸（原著是从崖壁上一道常春藤帘子后面的隧道进到地下码头），
从船屋顺着之字形石阶爬到入口庭院，走到礼堂东端门楼的橡木大门。人物不做，只有海格那盏灯笼代表"有人在带路"。

会动的东西：火车进站（整列车匀减速）、车头的白汽（按车速往后倒）、海格的灯笼（走路时上下晃）、十条小船（随水起伏）、
湖面的波纹、大楼梯第五段楼梯来回转、礼堂的火盆和壁炉的火。

夜里的光：车站煤气灯、车头灯、车厢里的灯、海格的灯笼、小船和码头的灯笼都会照亮周围（`LAMPS`），亮窗和灯都有一圈柔和的光晕。

为了这段运镜改过的场景：船屋石阶最后一段原来顶在拱廊南墙上是死路，现在往东延长到拱廊东头，那段垛墙开了个口；
门楼南面原来只有一扇格子窗，在窗下加了一对橡木大门（向外折开贴墙，夜里门洞发光）。

## 怎么看、怎么出片

- 页面里点"播放运镜"实时预览（每帧一个采样叠到前几帧上，动的时候有拖影），拖进度条可以跳到任何一镜，再点一下停止。
- `node tools/film.mjs --spp 6 --w 1280 --h 720 --out out/film --name hogwarts-tour` 逐帧渲染（每帧 6 个采样铺在半个帧时间里，
  有运动模糊）再用 ffmpeg 合成 mp4。`--every 48 --spp 3 --out out/filmcheck` 每 2 秒抽一帧，拼成小样检查机位。
- 调机位用 `node tools/probe.mjs 片段.js out/probe/x`：页面只搭一次，片段在模块里执行，可以临时改某一镜的关键帧、
  用 `tourStill('steps', 8, 4)` 出指定镜头指定时刻的一帧。
