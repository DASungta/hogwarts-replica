# 黄昏短片：暮色中的霍格沃茨（54.5 秒）

魔法短片（`docs/魔法短片.md`）你觉得不对：全是夜景远景，城堡只剩轮廓，复原的细节看不出来；那团光也不像书里的魔法。
这一版以展示城堡的精细度为主：镜头贴着石头走，从黄金时刻经过日落到蓝调时刻；魔法只用城堡里本来就有的东西点缀：
没人划自己漂进船屋的小船、日落时自己一扇扇亮起的窗户、会转的楼梯、漂浮的蜡烛和魔法天花板、出门的猫头鹰。

代码在 `src/js/89b-dusk.js`，用运镜的播放器放，网址加 `?cut=dusk`。

镜头之间都是直接切。第一版（57.5 秒）开头两镜一共 12.5 秒都有船，你说船还有点僵硬、画面给少一点：第一镜去掉了船，船屋那镜缩到 4.5 秒，只留一条船、慢速（3.2 米每秒）漂向水门。

## 做法

- **黄昏的光**（`setDusk(k)`）：k = 0 是黄金时刻（太阳在西南偏西 7°，斜着扫过湖岸那一面），0.5 日落，1 蓝调时刻（太阳在地平线下 4.5°）。
  一个数同时调太阳的方向、颜色和亮度，天顶和地平线的颜色，靠太阳一侧地平线的暖光（`SKY.uDuskA`）、对面的粉色光带和
  下面蓝灰的地影（`uDuskB`），日落后云不再被白天的天光照亮（`uCloudAmb`），雾，曝光和色阶。每个镜头一个 k，整片从 0.05 走到 0.88
- **灯亮不亮和是不是夜里分开了**（`ATMO.uLamp`）：以前窗户、灯笼、门洞的光都跟着 `uNight`，所以白天不能亮灯。
  现在自发光和局部灯光跟着 `uLamp`，天和光照跟着 `uNight`；`setNight` 两个一起设，原来的页面和运镜不变。黄昏时 `uLamp` 从 0.1 升到 0.9
- **窗户自己亮起来**：用魔法短片的"施法波前"（`SPELLU`），去掉金光带，改成一个从湖边往北推进的面：前三个镜头只有湖边
  （小船、船屋）亮着，第 4 个镜头里波前扫过礼堂和主塔
- **漂浮的蜡烛**（`BOB`）：`procMat` 加了一个投影之前的顶点钩子 `vbegin`，礼堂里离地 3.5 米以上的蜡烛（蜡烛身和火苗一起，
  还有火苗的光晕）按各自的位置慢慢上下浮动 6 厘米；高桌上的立烛不动
- **猫头鹰**（`buildOwls` / `owlsAt`）：车削的身体、带面盘和眼睛的头、扇形的尾，翅膀前缘圆、尖上是几根分开的初级飞羽、后缘一根根
  羽毛的弧；14 只，绕着猫头鹰塔在各自起伏的圆上飞，转弯时侧倾，扇翅（2.6～3.4 次每秒）和滑翔交替；一只雪鸮（海德薇），其余是
  灰林鸮和仓鸮的颜色

## 怎么出片

node tools/serve.mjs
node tools/film.mjs --spp 6 --w 1920 --h 1080 --out out/dusk/final --name hogwarts-dusk --params cut=dusk
