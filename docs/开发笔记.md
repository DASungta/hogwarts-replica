# 霍格沃茨城堡 · 电影版复刻（hogwarts-replica）

按 `athena-demo/` 的方法（参考图 → three.js 逐块搭建 → 和参考图并排比 → 改）复刻电影里的霍格沃茨城堡。
纯代码生成：没有模型、贴图和图片文件。城堡、山崖、湖、树、天空、窗户的光都在代码里。

和 `hogwarts-real/` 不同：那部片刻意不用电影造型；这里就是照着电影城堡（利维斯登 1:24 拍摄模型）复刻，
**只适合个人学习和演示**。城堡造型的版权属于华纳兄弟，公开发布（比如 B 站）之前要另外考虑。

第四轮（细修，2026-10-22）：不加建筑，对照电影剧照把崖壁、楼群和色调修了一遍。

  （石圈望钟楼、木廊桥、第八部高架桥）暗部和中间调明显偏绿青（绿通道比均值高 12%～19%），石头是灰的；

- 树：加了欧洲赤松（高光秃的树干、平顶的团状树冠），约四成；西侧深谷里、木廊桥下面种了树（照第三部剧照）。

## 踩过的坑

- 第一版崖壁上撒了几百块小石头，看起来像一堆土豆。改成：崖壁网格本身沿下坡方向做大尺度位移（岩体凸起、裂缝），
  陡坡统一用岩石着色器（竖向裂隙 + 倾斜岩层 + 朝上面长草），石块只留几十块大的在水边。
- 岩层条纹太规整，整面崖像一堵墙：给岩层加倾角、按噪声淡出，几何上的台阶感也减弱。
- 崖顶和建筑之间留了一条草皮，低机位看过去城堡像放在桌面上。崖顶线要贴着建筑的外墙走（礼堂、露台、正楼、温室围墙），
  礼堂的墙基往下延伸到崖里。
- 和模型照片比，第一版湖岸正楼太宽（60 米）：照片里大约 8 开间，按约 42 米改。
- 石阶如果按设计高度走会被山崖埋住：先按山崖高度拟合每个转折点，再在地形函数里沿石阶凿槽。
- 夜里湖面底部的一排亮条是窗户灯光的倒影，位置是对的（城堡在 60 米高的崖上，倒影落得很低）；把水面扰动调小后才看得清。
- 镜面反射复用主相机的抖动投影，阴影图在镜像那次渲染里更新、主渲染里复用，避免每个采样算两次阴影。
- 深谷第一版是对称的宽谷，看起来像一条长满草的山沟。改成：谷心往城堡挪，城堡一侧半宽 40 米、剖面很陡（岩石），对面半宽 86 米的缓坡长草。
- 海格小屋第一版立在坡上，下坡一侧露出好几米墙，像座小塔。在地形函数里给小屋整平一块地；整平高度必须先用小屋中心算一次再建网格，
  否则会取到网格扫到的第一个点，结果小屋被顶在一个土包上。
- 西侧山坡上的针叶林把石圈、小屋都挡住了：小路两边 14 米、地标周围 20 多米不种树，桥和小屋之间的开阔坡只留零星几棵。
- 木廊桥第一版太单薄：照模型把长廊加高到 4 米、屋顶加宽加厚并加一排小山墙，桁架格子放大（5.6 × 6.5 米），桥头圆塔放大到半径 4.6 米。
- 岩石裂隙在平滑的陡坡上会连成一张淡紫色的网：把裂隙的暗度减轻（0.45 → 0.62）。
- 北侧溪谷很窄（半宽 10～19 米），崖壁的"碎裂位移"会把网格推过谷心折叠，露出下面 60 米处的湖面，看起来像谷底有一片水和一块黑色斜板。
  溪谷附近把位移减到 25%。
- 天文塔的半圆塔第一版放在南面，和模型照片（从湖上看在右边，也就是东面）对不上，改到东面。
- 近看崖壁时，往陡壁上贴实例化的大石块（无论圆角方块还是低面数多面体）都像粘上去的枕头或气球，比光秃的崖壁更难看，最后去掉了。
  近处的岩石感要靠着色器里的大尺度凹凸和颜色变化，或者更细的地形网格。
- 值噪声取 |n*2-1| 的细线（想做"裂缝"）在平缓的面上会变成一圈圈等高线，不能用。
- 色调对齐时剧照只在浏览器里量（canvas 读像素，算分位数和色偏），不下载、不放进仓库。
- 车削体（LatheGeometry）顶点逐个平移时，轴线上的顶点（半径约 0）被 `continue` 跳过，结果留在世界原点：岩柱顶上拉出一根
  横跨画面的黑色长条。跳过的顶点也要一起平移。
- 树一多（禁林扩大后约 9800 棵）三角形数翻倍：松树冠的二十面体细分从 2 降到 1，单个采样从 50 毫秒回到 43 毫秒（RX 590）。
- 相机挂在室外场景下面。渲染室内场景时，three.js 不会更新"有父节点的相机"的世界矩阵，`lookAt` 改了朝向却不生效：
  室内镜头全都朝着默认方向。每个采样开始时手动 `camera.updateMatrixWorld()`。
- 铅条菱格窗的判断写反了（`1 - smoothstep(...)`），格子中间成了铅条，远看是一张白网。室外窗户也有同样的错，一起改了。
- GLSL 的 `smoothstep(a, b, x)` 在 a > b 时结果未定义：在 ANGLE/D3D 上机车的白汽整片变黑。改成 `1 - smoothstep(b, a, x)`。
- 屋顶只有朝上的一面，从站台底下看雨棚是透明的：加一层木板吊顶。
