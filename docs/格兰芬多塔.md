# 格兰芬多塔：第一人称参观（一镜到底）

`?cut=gryff`，代码在 `src/js/89d-gryffwalk.js`。没有配音、没有旁白，像有人领着你走一遍：从画像洞进公共休息室，
转一圈，走进东南角的圆拱门，顺着螺旋石梯转四圈上去，穿过走廊进男生宿舍，绕着铁炉走到哈利的床前。

- **一镜到底**：休息室、楼梯和宿舍是同一个场景（宿舍就搭在休息室楼上，`65-gryffindor.js`、`65b-gryffdorm.js`），
  镜头一直在走，中间没有剪接，也不换场景
- **第一人称**：眼高 1.62 米，像拿着稳定器走路，不加走路的上下颠动；看的方向按"看点"一个个平滑转过去（偏航和俯仰分开插值），
  上楼梯时看着前面的台阶、略微抬头
- **夜里**：壁炉的火、油灯、铜吊灯、楼梯井里的托架灯、宿舍床头的灯和铁炉的火光；窗外是夜色
- **速度**：休息室里走路约每秒 0.8 米，在看点停一停；楼梯上每秒 1.2 米（转得快，四圈约二十秒）；宿舍里每秒 0.6–0.75 米
- 近裁剪面在这部片子里改成 5 厘米（原来 0.5 米，走廊和楼梯井太窄，墙会被切掉）

| 段落 | 走到哪 | 看什么 |
|---|---|---|
